# Kali-Style-BashRC-Modifier-for-Termux


A simple Bash script that automatically customizes your Termux terminal by modifying the ".bashrc" file and applying a Kali Linux-inspired prompt.

Features

- Custom display name support
- Multiple color themes
  - Red
  - Green
  - Blue
  - Sky Blue
  - Pink
  - Yellow
- Automatic ".bashrc" configuration
- Lightweight and beginner-friendly
- Kali Linux style terminal prompt

Usage

Run the script, enter your preferred display name, choose a color theme, and the script will automatically update your Termux prompt.
